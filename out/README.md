# out/

Destination for files generated by the scripts in [`src/`](../src/):

- `disasm.sh` writes `<name>.asm` (disassembly) and `<name>.hexdump.asm` (hex dump).
- `asm_parser.py` writes `<name>.csv`, `<name>_isa_sets.csv`, and `<name>.asm` (extraction output).

Everything here is generated — safe to delete, and ignored by git except for this file.
