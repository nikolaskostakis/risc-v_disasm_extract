# out/

Destination for files generated by the scripts in [`src/`](../src/):

- `disasm.sh` writes `<name>.asm` (disassembly) and `<name>.mem` (hex dump).
- `isa_profiler.py` writes `<name>.csv`, `<name>_isa_sets.csv`, `<name>.asm` (extraction output), and `<name>.mem` (extraction hex dump, with `-eh`).

Everything here is generated — safe to delete, and ignored by git except for this file.
